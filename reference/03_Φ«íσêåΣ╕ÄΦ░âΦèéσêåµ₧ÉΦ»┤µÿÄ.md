# Q13计分与调节分析说明（R11结构原位修订）

Q13严格沿用Q11的29个变量、缺失规则和派生计分。唯一需要特别标记的是：字段名保持A/D，但R13题项语义已经更新。

- `self_A_pre/post`、`perceived_comment_A`：R13解释为“身心激活程度”；高激活既可表现为兴奋，也可表现为紧张。
- `self_D_pre/post`、`perceived_comment_D`：R13解释为预期/评论者行程掌控感。
- `information_amount`继续为Q26，不替换成平台可能出现性。
- planning三题全部有效才取均值；品牌前后各至少2/3有效；访问意向2/2有效；self变化=post-pre。
- 主要模型及C1/C2/C3计划对比沿用原方案；R13与R11必须按版本分层，不因字段名一致而假定A/D题项完全等值。
- 不按操纵识别、品牌显著性或self变化筛选材料或参与者。
