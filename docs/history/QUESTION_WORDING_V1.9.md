# V1.9 题项措辞调整说明

## 调整范围

本次只调整“此刻我的感受”板块中的即时自我控制感题项，不改变其他实验材料、随机化、数据库字段、题序或计分方式。

## 当前即时自我 PAD 题项

题干均为：**此刻我感到**。

- 愉悦度 `self_P`：非常不愉快—非常愉快；
- 唤醒度 `self_A`：非常平静—非常兴奋；
- 控制感 `self_D`：行程超出我的掌控—行程在我的掌控之中。

## 版本与兼容性

- 部署版本：`netlify-fullstack-v1.9`；
- 界面版本：`xhs-mobile-v1.8`；
- 材料修订编号：`R8`；
- 数据库变量名仍为 `self_D`；
- 仍按 1—7 分记录；
- 标准化仍使用 `(raw - 4) / 3`；
- CSV 导出、后台统计和数据库迁移无需修改。

不同修订版本的数据不应在未标记 `revision_id` 的情况下直接合并。
