# V1.7 评论区操纵检查题目

## 页面说明

下面几道题只评价刚才看到的六条评论，不用考虑帖子正文和图片。没有标准答案，按第一感觉选择即可。

## 题目

1. `perceived_comment_P`
   - 题目：看完这几条评论，你觉得大家整体心情是偏不开心，还是偏开心？
   - 1端：很不开心
   - 7端：很开心

2. `perceived_comment_A`
   - 题目：这些评论让你觉得大家当时的状态是偏平静、松弛，还是偏兴奋、带劲？
   - 1端：很平静／很松弛
   - 7端：很兴奋／很带劲

3. `perceived_comment_D`
   - 题目：从这些评论来看，大家更像是被行程和时间推着走，还是能自己安排、掌握节奏？
   - 1端：完全被安排推着走
   - 7端：完全能自己掌握

4. `emotion_label`
   - 题目：综合来看，这几条评论最接近哪一种感觉？
   - 选项：轻松开心、兴奋开心、紧张担心、比较客观没有明显情绪、其他。

## 研究处理原则

变量名、数据类型和后端表结构均未改变。正式分析不得依据操纵检查得分删除参与者，也不得将处理后的操纵检查得分直接作为主要模型协变量。
