## 技术字段与计分
respondent_id、wave_id、revision_id、base_material_id、condition_id、material_id、randomized、current_step及原时间/提交字段保留。
brand_image_pre/post：对应三题至少两题有效取均值。visit_intention：两题均有效后取均值。PAD单题保持1—7，标准化(raw-4)/3，缺失保持缺失。
新增comment_feeling_open，存responses.value_text，可空，最多1200字符；不会新增participants列。
emotion_label存选项原文，不存1—5的数字编号；新旧选项内容不同。
宽表新增questionnaire_revision_id、ui_version、deployment_version：本轮当前记录为Q9/xhs-mobile-v2.0/netlify-fullstack-v2.0；历史记录不补成新版。
stimulus_loaded仍为整篇帖子所有图片是否加载，不等价于评论文本曝光。base_time_sec、stimulus_time_sec仍沿用墙钟秒数。
统计当前轮；四类CSV保留全部历史记录。R9分析筛选revision_id=R9且wave_id=PRETEST-W2。
字段相同不代表新旧题目测量等值。self_D是预期行程掌控感。研究者组别目标不从/api/config泄漏为材料标签。
